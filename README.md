# GuRu

**GuRu** — Android-приложение для подготовки к ЕГЭ по русскому языку.

Приложение объединяет теоретические материалы, практические задания, варианты, сочинения и статистику обучения в одном месте. Пользователь может решать задания, отслеживать свой прогресс и возвращаться к ранее изученному материалу.

---

## Возможности

### 📚 Теория

Раздел с теоретическими материалами по русскому языку.

Материалы представлены в структурированном виде и могут загружаться с сервера и использоваться внутри приложения.

---

### ✏️ Практика

Пользователь может решать задания ЕГЭ и получать информацию о результате.

Поддерживаются:

- отдельные задания;
- задания по типам;
- просмотр подробной информации о задании;
- варианты;
- повторное решение;
- история попыток;
- статистика выполнения.

---

### 📝 Сочинение

В приложении предусмотрен отдельный раздел для работы с сочинением.

Результаты работы с сочинениями могут отображаться отдельно от обычных заданий и использоваться для формирования статистики.

---

### 📊 Статистика

GuRu собирает информацию о результатах пользователя и позволяет анализировать подготовку.

Доступны различные представления статистики:

- общая статистика;
- статистика по номеру задания;
- статистика по типу задания;
- статистика по варианту;
- статистика по сочинениям;
- последние попытки.

---

### 📈 Прогресс

Результаты пользователя сохраняются и синхронизируются с сервером.

Приложение использует локальное хранилище, поэтому данные о прогрессе могут обрабатываться независимо от сетевого слоя.

Для фоновой синхронизации используется `WorkManager`.

---

### 🔖 Избранное и шпаргалки

Пользователь может сохранять полезные материалы для быстрого доступа.

В проекте присутствуют отдельные компоненты для работы со:

- шпаргалками;
- избранными материалами;
- сохранёнными заданиями.

---

### 👤 Авторизация

Приложение поддерживает пользовательскую авторизацию.

В проекте реализованы:

- регистрация и вход;
- подтверждение электронной почты;
- восстановление пароля;
- Google Sign-In;
- управление токенами;
- автоматическое обновление авторизации;
- обработка выхода пользователя.

Для защиты отдельных операций также используется Google reCAPTCHA.
